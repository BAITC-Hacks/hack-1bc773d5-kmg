# Классификатор сообщений

Минимальный Python-скрипт читает пять сообщений из `messages.txt`, определяет
категорию (`справка`, `жалоба` или `другое`) и печатает короткий черновик ответа
на русском языке. Пустые строки пропускаются.

## Требования и запуск

Python 3.6 или новее. Используется только стандартная библиотека, установка
зависимостей не требуется. Из папки проекта запустите:

```sh
python classifier.py
```

## Правила

Классификация основана на ключевых словах без учёта регистра и не требует API-ключа:

- `очередь`, `холодная`, `пропал`, `не работает` → `жалоба` (проверяется первой).
- `справк`, `где`, `как получить` → `справка`.
- Если совпадений нет → `другое`.

Проверяется вхождение подстрок; правила простые и не понимают контекст.
Черновик ответа выбирается по категории.

## Пример вывода

```text
Сообщение: Как получить справку о месте учёбы?
Категория: справка
Черновик ответа: Уточните детали запроса, чтобы мы могли предоставить информацию.

Сообщение: В столовой очередь, еда холодная.
Категория: жалоба
Черновик ответа: Спасибо за сообщение. Уточните место и время проблемы.

Сообщение: Хочу записаться на консультацию завтра.
Категория: другое
Черновик ответа: Уточните детали запроса, и мы подскажем дальнейшие шаги.

Сообщение: Пропал Wi-Fi в корпусе B.
Категория: жалоба
Черновик ответа: Спасибо за сообщение. Уточните место и время проблемы.

Сообщение: Где парковка для гостей?
Категория: справка
Черновик ответа: Уточните детали запроса, чтобы мы могли предоставить информацию.
```
