# Фильтр алертов

Скрипт читает восемь событий мониторинга из `events.json`, выводит только
критичные события и в последней строке сообщает их количество.
События с уровнями `info` и `warn` пропускаются.

## Входные данные

Файл `events.json` в кодировке UTF-8 содержит JSON-массив объектов с полями
`event` (название события) и `level` (уровень), например:

```json
[{"event": "disk 90%", "level": "critical"}]
```

Фильтр проверяет точное равенство `level` строке `critical` с учётом регистра.
Количество рассчитывается по данным, а не задаётся заранее.

## Запуск

Требуется Python 3.6 или новее. Из корня репозитория выполните:

```sh
python 02-alert-filter/filter_alerts.py
```

Путь к JSON определяется относительно самого скрипта, поэтому текущая рабочая
папка не влияет на поиск файла. Если файл отсутствует или содержит некорректный
JSON, скрипт выводит сообщение об ошибке в stderr и завершается с кодом 1.

## Ожидаемый вывод

```text
disk 90%
payment failed
db timeout
критичных 3
```

Используется простой фильтр `if` и стандартная библиотека Python.
Внешние зависимости, AI и API-ключ не нужны.
